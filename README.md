# Laminat

A fast, native macOS viewer for Apache Parquet files. No Electron: AppKit + an embedded
[DuckDB](https://duckdb.org).

- **Quick Look** — select a `.parquet` file in Finder and press Space: schema, row count and the first rows.
- **Finder thumbnails** — `.parquet` icons show a miniature of the table.
- **Viewer** — double-click a file: a lazily loaded grid that scrolls through millions of rows, sort by
  clicking a column header, filter with the field under each header.
- **Export** — save the current view or a query result as CSV, Parquet or JSON Lines.
- **SQL** — query the file with DuckDB SQL (`SELECT … FROM <file name>` or `FROM t1`), with templates,
  history and cancellation.
- **Statistics** — per-column profile: nulls, unique values, min / max, mean, quartiles; histogram and
  top values of a selected column.

Requires macOS 15 or later (Apple Silicon or Intel).

## Install

Download `Laminat-<version>.dmg` from [Releases](https://github.com/priboy68rus/laminat/releases/latest),
open it and drag **Laminat** onto **Applications**. Later versions install themselves
(Laminat → Check for Updates…).

Laminat is not notarized (no paid Apple Developer account), so macOS blocks it the first time:

1. Open Laminat. macOS says it can't verify the app — click **Done**.
2. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to the
   message about Laminat, then confirm with your password or Touch ID.
   Or, in Terminal: `xattr -dr com.apple.quarantine /Applications/Laminat.app`
3. Launch Laminat once — this registers Quick Look and thumbnails.

If Space doesn't show the preview, enable **Laminat Quick Look** in
System Settings → General → Login Items & Extensions → Quick Look, then run
`qlmanage -r && killall Finder`.

## Using it

| | |
|---|---|
| ⌘1 / ⌘2 / ⌘3 | Data / SQL / Statistics |
| ⌘↩ | Run the query (or the selected part of it) |
| ⎋ | Cancel a running query |
| ⌘T | Open a file in a new tab |
| ⌘⇧T | Insert a query template |
| ⌘F | Find: column filters in the grid, find bar in the SQL editor |
| ⌘C | Copy selected rows as TSV |

**File → Export To → CSV / Parquet / JSON Lines** saves what the current tab shows — the file with its
sort and filters applied, or the SQL result — with full values and all columns.

In SQL the file is available under its file name without the extension and as `t1`. Drop more
`.parquet` files on the **Tables** sidebar (or the editor) to join them — they become `t2`, `t3`… Only read-only
statements run (SELECT, WITH, DESCRIBE, SUMMARIZE, …); results are capped at 1 000 000 rows.

## Build from source

Requires Xcode and [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```sh
brew install xcodegen
./scripts/build.sh
```

The script builds the Release configuration (so performance matches what users get), downloads the
pinned DuckDB library (`scripts/fetch-duckdb.sh`), generates the Xcode project, installs `Laminat.app`
to `/Applications` (replacing a downloaded release) and registers the extensions.

```sh
qlmanage -p samples/sample.parquet
```

### Developer CLI

`laminat-cli` renders and times the Quick Look preview, benchmarks grid paging and runs SQL:

```sh
xcodebuild -project Laminat.xcodeproj -scheme LaminatCLI -derivedDataPath build -quiet build
build/Build/Products/Debug/laminat-cli preview samples/types.parquet --runs 3 --html /tmp/preview.html
build/Build/Products/Debug/laminat-cli bench testdata/big_30m.parquet
build/Build/Products/Debug/laminat-cli exec "COPY (SELECT * FROM range(10)) TO '/tmp/t.parquet'"
```

### Test data

`scripts/make-testdata.sh` generates large files into `testdata/` (not committed): 30M rows / 1.7 GB and
501 columns.

### Release

1. Bump `MARKETING_VERSION` **and** `CURRENT_PROJECT_VERSION` in `project.yml` (Sparkle compares the
   build number), add a section to `CHANGELOG.md` (shown in the in-app update window).
2. Push a `v*` tag. GitHub Actions builds a universal, ad-hoc signed app, signs the zip with the Sparkle
   key, and publishes a release with `Laminat-<version>.dmg` (for people), `Laminat-<version>.zip` (for Sparkle)
   and `appcast.xml`. Tags with a `-`
   (`v0.2.0-beta1`) become pre-releases and are not offered as updates.

Self-update uses [Sparkle](https://sparkle-project.org): installed copies read
`releases/latest/download/appcast.xml` daily. The EdDSA private key is in the login keychain
(account `laminat`) and in the `SPARKLE_PRIVATE_KEY` repository secret — keep a backup: without it,
existing installs can't be updated automatically. To test an update locally, serve a signed appcast and
`defaults write com.priboy68rus.laminat LaminatFeedURL http://127.0.0.1:8765/appcast.xml`.

The icon is generated by `swift scripts/make-icon.swift`.
